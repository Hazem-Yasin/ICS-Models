# private/

Your own reference stills go here: screenshots of BioShock, Prey, Alien: Isolation, SOMA, Dead Space, Hardspace: Shipbreaker, Papers, Please, concept art, anything copyrighted that you want to look at while modelling.

**Everything in this folder except this file and `.gitkeep` is git-ignored.** It stays on your machine and is never committed or pushed. That is deliberate: those images belong to their studios.

Suggested layout (match the headings in `../ART_BOOK.md`):

```
private/
  bioshock/
  prey/
  alien-isolation/
  soma/
  dead-space/
  shipbreaker/
  papers-please/
  other/
```

Tips:

- Name files for what they show, not the game: `hand-tool-grip.png`, `terminal-red-light.png`.
- Take your own screenshots in-game (photo mode or F12). Press the key, don't download from the web.
- Note in the ART_BOOK, by file name, anything you want to remember about an image.
- Do not drop images here that you want in the repo. Those must be CC or public domain and go in `../images/` with an entry in `manifest.json` and a line in `../CREDITS.md`.

If you work from OneDrive, remember this folder syncs to your OneDrive even though git ignores it.
